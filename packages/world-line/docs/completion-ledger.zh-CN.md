## 已实现的明确边界

这些是功能的保护规则，不是留给下一批的实施项：

- 传统 profile 合入和完整 A/B 部署均保留；不同 home 全局配置通过完整部署交付，不静默改变其他 profile 的全局配置。
- 外部守护独立于 DSH Web；不会擅自安装开机启动。需要开机启动时把已提供的 `deployment run --yes` 接到既有系统服务管理器。
- 未知版本矩阵结果标为探索证据，不自动扩大 HostAdapter 认证范围；缺少 Chrome/秘密输入/可信基线会明确失败。
- 原始 trace 可能包含秘密，只能认证后主动预览/下载；自包含包拒绝包外嵌套本地依赖和外部软链接，用户需先纳入包或发布依赖。
- 旧缓存迁移使用新副本，核对后才删除旧实例；恢复、GC 和中断任务不会覆盖未知改动或自动重放写操作。
- SIGKILL 和故障注入验证的是进程中断恢复；没有声称完成硬件断电实测或运行中数据库一致性保证。

## 2026-09-08 画布与 HUD 交互修订

- 连续启停时，受控 React Flow 节点偶发丢失测量尺寸，节点和连线被隐藏、时间刻度仍在。为固定几何节点显式提供宽高；状态更新不重新适配视角，零尺寸容器不触发自动适配。
