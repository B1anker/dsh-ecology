## 修复依据

- **焦点边框裁切（P1）**：修改别名页面的输入框实际使用 `outline: 2px` 和 `outline-offset: 2px`，但 `.wl-panel-body` 左右只有 2px padding，并启用了滚动裁切。统一文本输入、选择器及按钮的内侧焦点环，输入框保持完整的金色边框；错误输入使用错误色。滚动与固定标题 / 底部操作区保留。
- **窄屏返回按钮重叠（P1）**：原“返回上个面板”绝对定位在右下角，与时间控制器重叠。将面板历史导航通过 React Context 交给公共 Panel，在标题栏提供带名称的返回图标；复核返回后显示正确面板。
- **任务列表密度（P2）**：原每项任务三个按钮各占一整行；改为标题 / 状态、时间、主操作、同排次级操作，降低重复操作占用的高度。
- **表单一致性（P2）**：统一输入高度、圆角、焦点、禁用、错误状态；标签页允许必要换行，下拉选项长文本可换行；底部操作增加分隔与间距。
- **文案与对比度（P2）**：插件输入不再放置两段过长示例；帮助区域显示简短说明而非整块空白。存储子页按操作呈现提示，技术统计说明仍在概览中保留。
