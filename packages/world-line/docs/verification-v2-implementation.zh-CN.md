# 验证体验与认证优化实施记录

2026-09-08。本轮处理日志误判、插件特例、重复登录和验证窗口突然关闭。

## 已实现

- 日志采集和核心断言分离。console、异常、传输失败、HTTP 4xx/5xx 记录来源和脱敏地址。目标宿主文档、脚本、样式加载失败以及加载器错误、稳定观察期间界面消失属于阻断；未知影响独立列为待确认。
- 核心界面出现后观察 5 秒并重新检查。一次浏览器结果只记录一条核心检查，不再复制为三个通过或失败。插件业务功能未自动测试单列覆盖范围，不自动调用模型或检查 API key。
- 移除插件包名和固定端口推断。旧记录不改写，新记录按策略版本 2 保存。报告包含结构化观察。
- 任务台、结果面板和画布区分失败、等待登录、待确认异常和未完成。必要检查 skip/warn 不能形成通过；可选检查失败不单独否决兼容性。
- 仅经认证、同源管理操作发起的实验，可以在十分钟内由 web-login 接受该实验的宿主原生会话。限定实验 home、loopback 连接及有效原生认证，同时支持 HTTP 与 WebSocket。没有复制正式 Cookie、关闭登录插件或给跨域请求添加认证头。CLI、后台升级和正式 home 默认不开启此能力；旧版登录插件继续使用正常登录流程。
- 可见 Web 验证结束后，关闭待测页面并展示独立结果说明，窗口保留五分钟或由用户关闭。实验服务照常退出，结果页明确说明服务已结束；它不是继续运行的试用实例。
- 影响待确认且其他必要检查通过时，用户可以单次显式接受风险。合入日志记录时间、策略和未决检查，不自动标记稳定点。该选项不进入自动安装流程；不能覆盖核心失败、等待登录或缺证据。移除运行前预先接受未知结果的复选框。
- v2 合入校验来源、候选 receipt 和宿主版本，试用或外部编辑改变候选内容后必须重验。旧 `accept-inconclusive` 不再绕过必要证据。
- 合入后的重启若确认核心失败仍回滚；仅缺浏览器或登录证据时保留已提交事务、明确提示验证待完成、不标记稳定点。

## 覆盖边界

当前宿主适配仍限已支持版本。浏览器证据覆盖宿主加载器错误面、核心界面稳定性及资源异常，不宣称逐个插件的所有业务能力已验证。按需来源运行基线、第三方声明式功能契约、跨进程认证恢复和持续试用实例的租约不是本轮实现，完整设计中仍保留为后续能力。

## 验证

单元测试覆盖核心资源 404、跨 origin API 异常、console/未处理异常、稳定期间界面消失、必要检查缺失、单次风险边界及候选 receipt 变化。登录测试覆盖默认关闭、正式 home 拒绝、目标 home、loopback、原生认证及过期。

真实 Chrome 验证了正常页面、未知影响和关键资源故障。临时隔离 DSH 安装当前 web-login 后，原生实验会话复用成功，47 个客户端入口启动，HTTP/WebSocket 无认证错误。Web UI 验证了进度、折叠诊断和待确认结果，没有页面脚本错误。未对正式 profile 执行插件安装或合入测试。

## 旧分支回归修复（2026-09-08）

实际从 ui-preview 创建的实验仍使用旧登录组件，不能复用新增的原生会话交接；用户选择保留该版本。待登录结果现在直接提供“打开本机验证浏览器并继续”，调用 interactive lab-verify，不重新安装插件。

重验旧实验出现 ERR_MODULE_NOT_FOUND，缺失 rescue-bundles.js。核实旧安装与开发 dist 文件共享 inode，构建原地覆写导致部分文件更新、新文件缺失。构建前解除已有硬链接；已受影响的八份 world-line 安装用完整构建目录原子置换，原目录保留在 dist.repair-* 便于定点回退。实测故障实验恢复启动；没有升级其登录组件。启动器现在保留脱敏完整输出，摘要优先展示真实 Error 行，不再只显示尾部括号。

验证：364 项单元测试通过，硬链接隔离测试通过，真实故障实验正常启动，浏览器 UI 确认直接按钮发送 interactive=true 的重验动作。
