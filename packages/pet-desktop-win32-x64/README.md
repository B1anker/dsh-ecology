# @seaveyon/dsh-pet-desktop-win32-x64

The desktop companion binary of [@seaveyon/dsh-pet](../pet) for Windows x64
(`win32`/`x64`): a single native executable under `bin/`. It is an optional
platform dependency of `@seaveyon/dsh-pet` — npm installs it automatically
on a matching machine and skips it everywhere else, so an install downloads
only the one binary its platform needs. The package is not meant for direct
use; install `@seaveyon/dsh-pet` instead.
